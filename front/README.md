# Frontend do Stock Flow

Aplicação Next.js com TypeScript. As páginas ficam em app/ e cada pasta com page.tsx corresponde a uma rota.

Execute npm.cmd install e npm.cmd run dev para iniciar em http://localhost:3000. O backend Spring Boot deve estar ativo em http://localhost:8080. Para trocar a URL, use a variável NEXT_PUBLIC_API_URL, seguindo front/.env.example.
